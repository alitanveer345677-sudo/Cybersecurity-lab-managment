## Project Description
A C program designed for managing cybersecurity lab resources, calculating total investments, and outputting formatted reports.

## Input
- Lab Name
- Number of Computers, Network Devices, and Security Tools
- Cost per Computer, Network Device, and Annual Software Cost

## Processing
- Computer Cost = Computers * Cost per Computer
- Network Cost = Network Devices * Cost per Device
- Total Investment = Computer Cost + Network Cost + Software Cost

## Output
Formatted terminal report displaying calculated costs and total investment.

```bash
gcc cyber_lab.c -o cyber_lab
